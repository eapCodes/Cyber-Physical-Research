# Cyber-Physical Research Lab

This repository is a technical learning lab focused on embedded systems, cybersecurity fundamentals, and cyber-physical systems.

## Purpose

The goal of this project is to build a foundation in how software, hardware, and security concepts connect in real-world systems such as industrial control systems, sensors, embedded devices, and critical infrastructure.

## Topics

- Embedded systems
- Arduino hardware experiments
- C and C++ fundamentals
- Cybersecurity concepts
- Cyber-physical systems
- Critical Infrastructure Protection (CIP)
- Technical documentation

## Repository Structure

- `hardware/` — Arduino and physical computing experiments
- `theory/` — Notes on programming, cybersecurity, and computer science fundamentals

## Tools Used

- Arduino Uno R4 WiFi
- C / C++
- Git and GitHub
- Linux / Windows development tools

## What I Am Learning

- How embedded devices interact with software
- How to document technical experiments clearly
- How cybersecurity applies to physical systems
- How to organize long-term technical research using GitHub
